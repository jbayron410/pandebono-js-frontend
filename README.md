# 🟣 Pandebono.JS - Frontend

Frontend application for Pandebono.JS, built with Angular for the AI Hackathon in Cartago.

## 🚀 Tech Stack
- Angular
- TypeScript
- RxJS
- Angular Material (optional)

## 📦 Installation

```bash
npm install

🧪 Run locally
ng serve

App will be available at:
http://localhost:4200

⚙️ Environment configuration

Update API URL in:
src/environments/environment.ts

Example:
export const environment = {
  production: false,
  apiUrl: 'http://localhost:8080'
};

🧩 Project Structure

src/
 ├── app/
 ├── assets/
 ├── environments/

 🚀 Deployment

This project is configured for deployment with Vercel.
